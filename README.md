# Ночник

Тёплый свет на экран, пока запущен Ночник. Цвет зафиксирован. Крутится только тусклость.

Страну программа не смотрит и ни от кого ничего не требует. Работает одинаково везде, без интернета.

Подсветку монитора не трогает, права администратора не нужны. На выходе картинка становится обычной.

Горячие клавиши по умолчанию: Ctrl+Alt+↑ и Ctrl+Alt+↓ меняют тусклость, Ctrl+Alt+N даёт обычный экран, пока не нажмёшь ещё раз. Любую можно переназначить в окне: щёлкни по кнопке и нажми сочетание. Esc отменяет, Backspace убирает. Если сочетание заняла другая программа, кнопка так и скажет.

Полоса до риски — тот же тёплый свет, слабее или как сейчас. Правее риски драйвер не принимает канал ниже 0.50, поэтому дальше экран прикрывает прозрачная плёнка, до 75% темноты. Клики сквозь неё проходят.

Закрытие окна прячет программу в трей. Второй запуск открывает окно, а не выключает свет.

## Устройство

Чистый Win32 и GDI+ на C++20, без рантаймов (статический CRT). Один исходник `night.cpp`; автозапуск из MSIX-пакета (C++/WinRT, `StartupTask`) вынесен в `startup.cpp`.

Настройки лежат в `%AppData%\Night\config.txt`, журнал — рядом, `log.txt`.

Ключи запуска: `--background` (без окна), `--reset` (закрыть запущенную копию или просто вернуть обычную гамму), `--check [файл]` (самопроверка расчётов, код возврата 0/1), `--check-ui` (создать окно и сразу закрыть).

## Сборка и пакет

Нужны Visual Studio Build Tools (C++) и Windows SDK.

```
powershell -ExecutionPolicy Bypass -File build.ps1      # build\Night.exe, затем --check
powershell -ExecutionPolicy Bypass -File package.ps1    # dist\Night-<версия>-x64.msix, Night.cer, Install.ps1
```

Версия — в `version.h`, одно место для exe, ресурсов и пакета. Пакет подписан самоподписанным сертификатом `CN=Nochnik` (хранится в `Cert:\CurrentUser\My`, чтобы обновления подписывались тем же ключом).

## Установка

Рядом должны лежать `Night-*-x64.msix`, `Night.cer` и `Install.ps1`. Запустить `Install.ps1` (правый клик → «Выполнить с помощью PowerShell»): один запрос UAC нужен только на то, чтобы доверить сертификат этому компьютеру, сам пакет ставится от пользователя. Прежняя сборка на .NET останавливается, её запись автозапуска убирается; если автозапуск был включён, он переносится.

Тот же номер версии повторно не ставится: чтобы обновить пакет, поднимите версию в `version.h`.
