# Ночник

Тёплый свет на экран, пока запущен `Night.exe`. Цвет зафиксирован. Крутится только тусклость.

Страну программа не смотрит и ни от кого ничего не требует. Работает одинаково везде, без интернета.

Подсветку монитора не трогает, права администратора не нужны. На выходе картинка становится обычной.

Горячие клавиши по умолчанию: Ctrl+Alt+↑ и Ctrl+Alt+↓ меняют тусклость, Ctrl+Alt+N даёт обычный экран, пока не нажмёшь ещё раз. Любую можно переназначить в окне: щёлкни по кнопке и нажми сочетание. Esc отменяет, Backspace убирает. Если сочетание заняла другая программа, кнопка так и скажет.

Полоса до риски — тот же тёплый свет, слабее или как сейчас. Правее риски драйвер не принимает канал ниже 0.50, поэтому дальше экран прикрывает прозрачная плёнка, до 75% темноты. Клики сквозь неё проходят.

Закрытие окна прячет программу в трей. Второй запуск открывает окно, а не выключает свет.

Сборка:

```
powershell -ExecutionPolicy Bypass -File build.ps1
```
